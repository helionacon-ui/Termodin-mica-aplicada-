Práctica y laboratorio

Prácticas I1 e I2

La asignatura trabaja las prácticas con EES (Engineering Equation Solver). Aquí tienes el equivalente en Python: se ejecuta en cualquier ordenador, muestra la salida que hay que esperar y reproduce en el navegador los cálculos principales. Si tu grupo usa EES, los resultados deben coincidir dentro de la precisión de las tablas.

Lo esencial

  • Dos sesiones de 2 horas (I1 e I2). La asistencia pesa el 15 % por sesión.
  • La entrega pesa el 70 %: un informe con código, salida y la interpretación pedida.
  • Lo que no puede faltar en cualquier entrega: qué calculas, de dónde sale cada dato y si el resultado tiene sentido físico.

Qué suele fallar

  • Las tablas de estos scripts son reducidas (anclas de las tablas de Moran). Sirven para practicar. Para exámenes usa las tablas completas.
  • Unidades coherentes: presiones en kPa, temperaturas en °C en las tablas de agua y en K en las fórmulas de gas.
  • Un error de programa puede dar un resultado plausible. Antes de creerlo, comprueba un caso conocido (p_sat(100 °C) ≈ 101,3 kPa).
Más a fondo: Qué es EES y qué pide cada práctica

EES resuelve sistemas de ecuaciones no lineales con propiedades termodinámicas incorporadas. La práctica I1 enseña a introducir un problema básico (estado del agua, balance de energía). La práctica I2 estudia un ciclo completo y muestra cómo cambian sus resultados al variar un parámetro. Python hace lo mismo con más trabajo manual, y por eso aquí las tablas son explícitas.

Práctica I1 · Estado del agua y región de trabajo

Antes de empezar: qué piden y qué teoría usas

Objetivo: dada una temperatura y una presión, decidir la región (líquido comprimido, mezcla o vapor sobrecalentado) y calcular el título cuando hay mezcla.

1Descargar el script y mirar la estructura

El script tiene tres partes: una tabla reducida de saturación, funciones de interpolación y el bloque principal con los cuatro casos de prueba.

Ejecuta el script. La salida que debes obtener es la siguiente.

"""Práctica I1 · Estado del agua y del aire húmedo con Python.

Equivalente en Python de los problemas básicos que se resuelven con EES en la práctica I1.
Usa tablas reducidas (anclas de las tablas A-2 y A-3 de Moran y Shapiro) con interpolación lineal.
Para los exámenes, usa siempre las tablas completas publicadas. Las cifras son de práctica.

Ejecutar:  python3 practica_I1_agua.py
"""
import math

# Tabla reducida de saturación del agua: T [°C] -> P_sat [kPa]
T_TAB = [0.01, 20, 50, 100, 150, 200, 250, 300]
P_TAB = [0.6113, 2.339, 12.35, 101.33, 476.2, 1554.9, 3973.0, 8587.9]
# Anclas de propiedades de saturación (20, 100, 200 °C)
ANCLAS_T = [20.0, 100.0, 200.0]
ANCLAS = {
    "v_f": [0.001002, 0.001043, 0.001157],
    "v_g": [57.79, 1.673, 0.12736],
    "h_f": [83.96, 419.04, 852.45],
    "h_g": [2537.4, 2676.1, 2792.2],
}


def interpola(xs, ys, x):
    """Interpolación lineal de ys en xs; si x está fuera, recorta al extremo."""
    if x <= xs[0]:
        return ys[0]
    if x >= xs[-1]:
        return ys[-1]
    for i in range(len(xs) - 1):
        if xs[i] <= x <= xs[i + 1]:
            t = (x - xs[i]) / (xs[i + 1] - xs[i])
            return ys[i] + t * (ys[i + 1] - ys[i])


def p_sat(T):
    """Presión de saturación [kPa] a T [°C]: interpolación lineal en ln(p)."""
    lnp = [math.log(p) for p in P_TAB]
    return math.exp(interpola(T_TAB, lnp, T))


def T_sat(P):
    """Temperatura de saturación [°C] a P [kPa] (inverso de p_sat)."""
    lnp = [math.log(p) for p in P_TAB]
    return interpola(lnp, T_TAB, math.log(P))


def region(T, P):
    """Región del agua con T [°C] y P [kPa]."""
    ps = p_sat(T)
    if abs(P - ps) / ps < 0.005:
        return "mezcla saturada (P = p_sat)"
    if P < ps:
        return "vapor sobrecalentado (P < p_sat)"
    return "líquido comprimido (P > p_sat)"


def titulo_desde_v(T, v):
    """Título x y entalpía h [kJ/kg] en mezcla saturada a T [°C] con volumen v [m³/kg]."""
    vf = interpola(ANCLAS_T, ANCLAS["v_f"], T)
    vg = math.exp(interpola(ANCLAS_T, [math.log(x) for x in ANCLAS["v_g"]], T))
    if v < vf:
        return None, "líquido comprimido (v < v_f)"
    if v > vg:
        return None, "vapor sobrecalentado (v > v_g)"
    x = (v - vf) / (vg - vf)
    hf = interpola(ANCLAS_T, ANCLAS["h_f"], T)
    hg = interpola(ANCLAS_T, ANCLAS["h_g"], T)
    return x, hf + x * (hg - hf)


if __name__ == "__main__":
    print("== 1. Presión de saturación")
    for T in (20, 100, 150):
        print(f"p_sat({T} °C) = {p_sat(T):.1f} kPa")

    print("\n== 2. Temperatura de saturación a 101,33 kPa")
    print(f"T_sat(101,33 kPa) = {T_sat(101.33):.1f} °C")

    print("\n== 3. Región del agua")
    for T, P in [(150, 500), (100, 101.33), (200, 1000)]:
        print(f"T = {T} °C, P = {P} kPa -> {region(T, P)}")

    print("\n== 4. Título desde v (mezcla a 100 °C)")
    x, h = titulo_desde_v(100, 0.9)
    print(f"v = 0,9 m³/kg -> x = {x:.3f}, h = {h:.1f} kJ/kg")
4Probar en el simulador

Cambia T y P y mira cómo cambia la región. Es la misma lógica que el script.

Resultado final

Interpretación pedida (propuesta de la guía; la práctica oficial puede pedir otra cosa): explica en 5 líneas por qué a 150 °C y 500 kPa el agua es líquido comprimido, y por qué a 100 °C y 101,33 kPa hay mezcla. Usa las palabras «p_sat», «región» y «título».

"""Práctica I2 · Análisis de un ciclo Brayton ideal (aire frío) con Python.

Equivalente en Python del análisis de ciclos con EES de la práctica I2.
Supone c_p y k constantes (aire frío). Compara resultados al cambiar r_p.

Ejecutar:  python3 practica_I2_ciclo.py
"""
import math

CP = 1.005   # kJ/(kg·K)
K = 1.4      # cociente de calores específicos
R = 0.287    # kJ/(kg·K)


def brayton(rp, T1, T3):
    """Estados y trabajos de un Brayton ideal. T en K, rp adimensional."""
    e = (K - 1.0) / K
    T2 = T1 * rp ** e             # compresión isentrópica
    T4 = T3 * rp ** (-e)          # expansión isentrópica
    wc = CP * (T2 - T1)           # trabajo del compresor (kJ/kg)
    wt = CP * (T3 - T4)           # trabajo de la turbina (kJ/kg)
    qin = CP * (T3 - T2)          # calor aportado (kJ/kg)
    wn = wt - wc                  # trabajo neto (kJ/kg)
    return {"T2": T2, "T4": T4, "wc": wc, "wt": wt, "wn": wn, "qin": qin,
            "eta": wn / qin, "bwr": wc / wt}


if __name__ == "__main__":
    T1, T3 = 300.0, 1200.0
    print(f"Ciclo base: T1 = {T1:g} K, T3 = {T3:g} K")
    r = brayton(8.0, T1, T3)
    for clave in ("T2", "T4", "wc", "wt", "wn", "qin", "eta", "bwr"):
        print(f"{clave:>4s} = {r[clave]:.4g}")

    print("\nBarrido de la relación de compresión:")
    print(" r_p    eta [%]   w_neto [kJ/kg]   relación de trabajos")
    for rp in (2, 4, 6, 8, 10, 12, 14, 16):
        b = brayton(rp, T1, T3)
        print(f"{rp:4d}   {100 * b['eta']:7.2f}   {b['wn']:12.2f}   {b['bwr']:12.3f}")

    print("\nComprobación con la fórmula cerrada: eta = 1 - rp^(-(k-1)/k)")
    print(f"eta = {100 * (1 - 8 ** (-(K - 1) / K)):.2f} %  (r_p = 8)")
